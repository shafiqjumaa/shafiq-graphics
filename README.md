# Shafiq Graphics — معرض المشاريع

المستودع الخاص بالموقع الشخصي لمصمم الجرافيك شفيق جمعة. هذا الفهرس يجمع أهم المشاريع المنشورة على GitHub، مرتبة بحسب الأولوية المهنية.

## ⭐ المشروع الرئيسي

### [DesignerFlow — إدارة أعمال المصمم](https://github.com/shafiqjumaa/Designer-invoice)

**[فتح التطبيق](https://shafiqjumaa.github.io/Designer-invoice/)**

إدارة العملاء والمشاريع والفواتير والعقود والحسابات للمصمم المستقل، مع دعم PWA وإعداد اختياري للمزامنة عبر Firebase.

## 🎨 أدوات للمصممين

| المشروع | الفكرة | المستودع |
| --- | --- | --- |
| DesignerFlow | إدارة العملاء والفواتير وأعمال المصمم | [Designer-invoice](https://github.com/shafiqjumaa/Designer-invoice) |
| Carousel Studio Pro | إنشاء كاروسيلات لمنصات التواصل | [Carousel-Studio-Pro](https://github.com/shafiqjumaa/Carousel-Studio-Pro) |
| BRAND//FORGE | تخطيط وتطوير اتجاهات الهوية البصرية | [Web-App](https://github.com/shafiqjumaa/Web-App) |
| Prompt Vault | حفظ البرومبتات وتحليلها وتصنيفها | [CityBuilder](https://github.com/shafiqjumaa/CityBuilder) |

> **ملاحظة:** اسم المستودع `CityBuilder` لا يعكس محتواه الحالي (`Prompt Vault`)، كما أن `Web-App` يحتوي على `BRAND//FORGE`. تم إظهار الأسماء الفعلية هنا دون تغيير مسارات المستودعات أو روابط النشر.
